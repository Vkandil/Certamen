# Certamen — 30s motion video

## Voice-over script (ElevenLabs, bracket audio tags)

```
[calm, confident] Ask one AI... you get one opinion.
[short pause] [intrigued] Ask four... [short pause] you get a debate.

[warm] This is Certamen. [softly] Latin for "contest."

[brisk, rhythmic] Several models answer on their own.
Then they critique each other, anonymously.
And an arbiter rules: [measured] consensus, dissent, and what to verify.

[pause] [reassuring, lower] No backend. No account. No tracking.
Just your browser, and your key.

[pause] [confident, building] Certamen. Open source.
[emphatic] Let the models argue.
```

~65 words, about 28–32 s at an ad pace.

## Storyboard (timed to the voice)

| Time | Line | Motion |
|---|---|---|
| 0–3s | Ask one AI… one opinion | A single grey chat bubble types out an answer, then flattens to a line. |
| 3–6s | Ask four… a debate | The bubble splits into the four logo petals (terracotta, ochre, olive, blue), which orbit and clash. |
| 6–9s | This is Certamen | The petals snap into the logo. CERTAMEN is carved in a Roman serif on stone, with "lat. *contest*" beneath it. |
| 9–12s | Several models answer | Four tinted columns stream text in parallel. |
| 12–15s | Critique each other, anonymously | Model names are masked to Contendens A/B/C/D, and the columns shuffle while review arrows cross between them. |
| 15–20s | An arbiter rules | The streams converge on the arbiter, and a synthesis card builds: Consensus / Dissensus / To verify. |
| 20–25s | No backend… your key | Kinetic type stamps each phrase. A browser frame closes around a key. |
| 25–30s | Open source. Let the models argue. | The logo resolves, followed by the end card with vkandil.github.io/Certamen and the GitHub repo. |

Visual system: the app's own tokens (stone `#F4EEE3`, ink `#1B1A17`, hairlines, hard corners, Georgia display). The four palette colors appear only as model identity, the same rule as `docs/DESIGN.md`.
